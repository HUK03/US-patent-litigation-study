# 디자인어라운드 및 방어적 특허 포트폴리오

[상위 목차(ko/README.md)](../README.md)


> **빠른 참조(Quick Reference):** 디자인어라운드는 특허위협에 대한 가장 완전한 해법입니다(지속침해 제거, 금지명령 리스크 제거, 장래손해 차단). 강한 방어 포트폴리오는 경쟁사 상호라이선스 레버리지와 NPE 억지력에 기여합니다.

---

## 1. 소송 방어수단으로서 디자인어라운드

디자인어라운드는 피소제품이 더 이상 청구항을 실시하지 않도록 바꾸는 것입니다(요소 제거/대체/다른 구현).

### 왜 중요한가
1. 장래 침해 중단
2. 금지명령 리스크 제거
3. 손해기간 축소
4. 고의침해 반박의 선의 증거
5. 합의 레버리지 강화

### 착수 시점
| 시점 | 상황 | 메모 |
|---|---|---|
| 소제기 전(FTO 단계) | 최적 | 비용 최소, 과거손해 최소 |
| 경고장 후 | 양호 | 제소 전 구현 가능 |
| 소장 후 | 허용 | 장래손해 차단, 과거손해는 잔존 |
| Markman 후 | 불리 해석 대응 | 회피 요소가 명확해짐 |
| 재판 중/후 | 늦지만 유효 | 금지명령·ongoing royalty 방어 |

## 2. 디자인어라운드 방법론

### Step 1: 회피 대상 청구항 매핑
독립항별 요소를 나열하고 제품 구현과 대응시켜 최소 1요소 이상을 제거/변경해야 합니다.

### Step 2: 대안 평가

| 대안 | 기술 실현성 | 구현 기간 | 법률 리스크 |
|---|---|---|---|
| 기능 제거 | 높음(비핵심 시) | 짧음 | 가장 낮음 |
| 선행기술 방식 채택 | 높음 | 짧음~중간 | 낮음 |
| 구조적으로 다른 구현 | 중간 | 중간 | 중간(DOE 리스크) |
| 라이선스 기술 채택 | 높음 | 짧음~중간 | 낮음(범위 명확 시) |

### Step 3: 법률 검토
엔지니어링 작업은 반드시 IP counsel 지휘 하에 수행.
- 엔지니어 독자 침해분석 문서화 금지
- "법률자문을 위한 기술정보 제공" 형태로 소통

### Step 4: 디자인어라운드 적정성 의견서
외부 특허변호사의 서면 의견으로 문언침해+DOE 모두 비침해 확인.

### Step 5: 구현 및 기록
- 구현일 정확히 기록(손해 중단 시점)
- 버전관리/빌드로그/배포기록 보존
- 가능하면 원고의 불소송합의(covenant) 확보
- 제품문서 업데이트

## 3. 방어적 특허 포트폴리오 구축

### 대기업에 왜 필요한가
| 기능 | 방어 포트폴리오의 효과 |
|---|---|
| 상호라이선스 레버리지 | 경쟁사 소송 시 countersuit 가능 |
| 억지력 | 공격소송 유인 감소 |
| NPE 방어 | 직접 억지는 약하지만 IPR 반격력 증가 |
| 금지명령 방어 | ITC/법원에서 협상력 확대 |

### 구축 전략
- 기술영역별 취약지대 지도화
- continuation 전략적 출원
- 방어용 특허 인수(경쟁사 핵심제품/활성 NPE 영역 중심)

### Defensive Aggregator 활용
| 조직 | 모델 | 적합 |
|---|---|---|
| LOT Network | 이전 시 상호 라이선스 | NPE 이전특허 방어 |
| OIN | Linux 관련 상호 무상 라이선스 | 오픈소스 사용자 |
| Unified Patents | 집단 IPR 방어 | 특정 NPE 영역 효율 방어 |
| RPX | 특허 인수+라이선스 프로그램 | 포괄적 NPE 방어 |

🌏 **한국 기업 권고:** LOT/OIN 기본 가입 + Unified zone/RPX 멤버십의 비용대비 효과를 정기 검토.

## 4. 특허 마킹 준수

35 U.S.C. §287에 따라 특허권자가 제품을 적정 마킹하지 않으면 소제기 전 손해배상 회수가 제한될 수 있습니다.

피고 점검사항:
- 원고/라이선시가 실시제품을 판매하는가?
- 마킹이 적법한가?
- 미준수면 손해기간이 실제 통지 이후로 제한될 수 있는가?

### Virtual Marking
AIA 이후 URL 기반 가상마킹("Patent/Pat." + URL)이 허용됩니다.

---

## 5. 표준기구 참여와 FRAND

한국 기술기업의 SEP 환경 관리:
- **Licensor 측:** SEP 선언 시 FRAND 의무 준수 필요
- **Licensee 측:** SEP 주장받으면 FRAND 요율 및 SSPPU 안분 요구
- ITC에서는 FRAND를 공익 항변으로 활용 가능

## 6. 특허 워치 프로그램

### 무엇을 모니터링할 것인가
| 범주 | 방법 | 주기 |
|---|---|---|
| NPE 포트폴리오 인수 | RPX/Lex Machina 알림 | 주간 |
| 경쟁사 신규 출원 | USPTO/EPO 알림 | 월간 |
| continuation 동향 | Google Patents/상용 알림 | 월간 |
| 관련 PTAB 사건 | PTAB/Docket Navigator | 월간 |
| ITC 제소 동향 | EDIS/Lex Machina | 주간 |
| 동종 업계 피소 동향 | PACER/Lex Machina | 주간 |

### 알림 대응
```
신규 특허 알림 수신
  ├─ NPE 보유자인가? → 즉시 IP counsel escalation
  ├─ 현행 제품 관련인가? → FTO 의뢰
  ├─ 차세대 제품 관련인가? → 다음 게이트 반영
  ├─ watch family continuation인가? → 기존 분석과 비교
  └─ 무관한가? → 근거 기록 후 종료
```

🌏 **한국 기업 메모:** 고빈도 NPE 타깃 환경에서는 분기 배치가 아닌 상시(real-time) 감시 체계가 필요합니다.

## 7. 2026 개정 부록: ODP 실사와 영업비밀 연계 리스크

### A. ODP/PTA 포트폴리오·M&A 실사 규칙

PTA 포함 최장 만료 특허가 있는 패밀리는 출원/등록 타임라인 감사를 의무화합니다.

1. 패밀리 내 최초 출원·최초 등록 특허 식별
2. PTA 포함/제외 만료일 매핑
3. *Cellect*/*Allergan* 기준으로 리스크 분류

후속 출원 특허가 실질적 존속기간 연장 수단이면 ODP 무효 리스크를 가치평가에 반영합니다.

### B. 클린룸 절차를 채용/통합 기본통제로 상향

경쟁사 인력 채용·외부 코드 접촉 가능성이 있으면 다음 통제를 문서화합니다.

- 인력/역할 분리
- 접근권한·저장소 분리
- 지시 로그·준수 확인서
- 결과물 독립검증 기록

### C. 글로벌 징벌적 노출 비교표(경영진 브리핑용)

| 관할/청구 유형 | 2025~2026 집행 신호 | 매뉴얼 반영 포인트 |
|---|---|---|
| 미국 특허 | 법정상 최대 3배 증액 중심 | 고의성 통제·의견서 절차 유지 |
| 미국 영업비밀 | 대규모 모범적 배상 가능 | 클린룸·인력이동 통제 강화 |
| 한국 특허/영업비밀 | 징벌배상 배수 확대 시행 | 한·미 컴플라이언스 동기화 |
| 중국 IP 법원 | 징벌배상 활용 증가 추세 | 중국 소송 하방위험 별도 반영 |
| 브라질 특허 | 전형적 징벌배상은 제한적이나 일일 강제금 리스크 | 금지명령 준수 운영 통제 |

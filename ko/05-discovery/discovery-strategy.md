# 증거개시 전략 (Discovery Strategy)

[상위 목차(ko/README.md)](../README.md)


> **빠른 참조(Quick Reference):** 특허 소송의 discovery는 비대칭입니다. 원고는 피고의 기술·재무 자료를 요구하고, 피고는 원고의 라이선스 이력·발명자 기록을 확보해야 합니다. 생산 범위, 특권, 소스코드 프로토콜을 엄격히 관리하면서 손해배상 방어의 핵심인 비교가능 라이선스(comparable licenses)를 공격적으로 확보하십시오.

---

## 1. 특허 discovery의 특수성

특허사건에는 일반 민사와 다른 고유 증거범주가 있습니다.
- 기술문서(소스코드, 설계명세)
- 재무데이터(매출/원가/이익)
- 발명자 증언
- 출원경과(공개자료이나 완전성 검증 필요)
- 라이선스 이력(손해배상 방어 핵심)
- SEP 문서(FRAND 분석)

---

## 2. 로컬 특허규칙: 자동 공시

대형 관할은 공식 문서요청 이전에도 침해/무효 주장서를 일정표에 따라 자동 교환하도록 합니다.

| 공시 항목 | 제출 당사자 | 통상 기한 | 요구 내용 |
|---|---|---|---|
| 침해 주장서 | 원고 | Rule 26(f) 후 14–45일 | 청구항-제품 클레임차트, 피소제품 특정 |
| 무효 주장서 | 피고 | 원고 주장서 후 14–45일 | 각 청구항 선행기술 차트, §101/102/103/112 근거 |
| 청구항 해석 차트 | 양측 | 로컬 규칙 | 분쟁용어별 제안 해석 |
| 문서 생산 | 양측 | 주장서 제출 시 | 주장 뒷받침 문서 |

**중요:** 무효 주장서는 선행기술 포지션을 고정(lock-in)합니다. 기한 내 특정하지 않은 선행기술은 이후 사용 제한 가능성이 큽니다.

## 3. 피고의 문서 생산 전략

### 범위 관리
피고 목표는 Rule 26(b)(1)의 **관련성+비례성**을 충족하면서 다음을 최소화하는 것:
- 민감한 영업정보 과잉 공개
- 특권 포기
- 불필요한 영업비밀 노출

**계층형 custodian 접근:**
1) 핵심 custodian(설계 엔지니어/PM): 광범위 생산
2) 주변 custodian: 협의로 범위 축소
3) 고위임원: 피소제품·특허 직접 관련 커뮤니케이션으로 한정, 과도한 apex deposition 대응

### 기술문서 생산

| 범주 | 생산 전략 |
|---|---|
| 설계명세/아키텍처 문서 | 비관련 제품정보는 적절히 가림(redaction), 고등급 비밀표시 |
| 소스코드 | 별도 프로토콜 필수 |
| CAD/회로도 | AEO(Attorneys' Eyes Only) 지정 |
| 버그리포트/테스트결과 | 피소 기능 관련분으로 범위 한정 |
| 제품 로드맵 | 피소 기능 한정 + 비관련 사업전략 가림 |

### 소스코드 프로토콜
- 전용 오프라인(air-gapped) 장비 제공
- 대리인 사무실 내 열람, 원격접속 금지
- 촬영/무단복사/전송 금지
- 접근자 제한(통상 외부대리인+전문가)
- 접근 로그 유지
- 인쇄 요청 페이지 수 제한 및 사전검토

🌏 **한국 기업 메모:** 한국 내 저장소(Git 서버 등) 연계 생산은 한국 IT팀-미국 대리인 간 초기 조율이 필수.

### 재무자료
원고는 피소제품 매출·원가·이익을 광범위 요청합니다.

**피고 전략:**
- 가능하면 제품 전체가 아닌 **피소 기능/구성요소 범위**로 생산
- 회계 시스템이 제품 단위만 지원하면 기능 단위 안분 분석 가능성 검토
- AEO 등급으로 세분화 제출
- 법원 명령 없는 미래 예측치 생산은 제한

## 4. 원고로부터 확보해야 할 우선 discovery

### 비교가능 라이선스(손해배상 방어 최우선)
피고의 최중요 타깃은 원고의 기존 라이선스 이력입니다(Georgia-Pacific 핵심 증거).

요청 항목:
- 주장 특허 관련 모든 라이선스 계약
- 동일 패밀리(continuation/divisional) 라이선스
- 동일 기술영역 비교가능 라이선스
- 동일 특허 관련 과거 소송의 합의+라이선스 자료
- 로열티율·협상 관련 커뮤니케이션

**의의:** 동일 특허를 저율로 라이선스한 전력이 있으면 고율 요구를 약화시킬 수 있습니다.

### 발명자 기록
- 연구노트, conception/reduction-to-practice 자료
- 발명자-출원대리인 커뮤니케이션
- 발명자의 과거 발표/논문(§102 선행기술 가능)
- 발명자의 선행기술 인지 정황

### 과거 소송 자료
- 동일 특허 관련 과거 생산문서
- 과거 claim construction 명령
- 과거 손해배상 전문가 보고서

### NPE 원고의 자금·사업모델
NPE의 자금조달·투자구조·소송펀더 영향력은 관할에 따라 개시 대상이 될 수 있음.

## 5. 피고가 초기에 던져야 할 주요 interrogatory

| 질문 | 목적 |
|---|---|
| 주장청구항 conception/reduction-to-practice 관련 지식인 전원 특정 | 발명자·증인 확보, §102 관련 단서 |
| 주장 특허 관련 라이선스/불소송합의/합의계약 전부 특정 | 손해배상 핵심 |
| 출원 전 원고가 알고 있던 선행기술 특정 | inequitable conduct/materiality 단서 |
| (ITC 병행 시) domestic industry 근거 특정 | ITC 분석 |
| 고의침해 주장 근거 특정 | 지식 시점·경로 특정 강제 |
| 동일 특허 과거 소송/청구항 해석/무효 판결 특정 | issue preclusion 검토 |
| 원고가 특허를 실시(practice)한다고 주장하는 제품/서비스 특정 | domestic industry/FRAND 분석 |

## 6. 증언녹취(deposition) 전략

### 발명자 증언녹취
가치가 매우 높은 타깃.
목표:
1. 실제 발명 범위 확인(과도한 청구범위 제한)
2. 발명자 인지 선행기술 자백 확보
3. 출원 전 공개·사용 사실 확인
4. POSITA 수준 정교화
5. conception/reduction-to-practice 시점 확정

준비: 발명자 서신·연구노트·출원경과 사전 분석.

### 피고 30(b)(6) 방어
- 통지 주제를 협의로 축소
- 주제별 최적 증인 분리 지정
- 30(b)(6) 진술은 회사에 구속력 → 철저 준비
- 특권 질문 대응 훈련
- 🌏 한국기업은 통역(준비+본 녹취) 체계를 조기 구축

### 제3자 subpoena(Rule 45)
- 전 직장/대학/표준단체 선행기술
- 동일 특허 과거 라이선시의 비교 라이선스 자료
- 피소제품 구성요소 공급사 기술문서

## 7. E-Discovery 운영

### 비례성(proportionality) 논리
Rule 26(b)(1) 비례성 요소(분쟁금액, 쟁점 중요성, 자원, 대체 취득 가능성, 부담/비용)를 적극 활용해 과도한 요청을 제한.

예:
- 전사 차원의 "모든 커뮤니케이션" 요청 저지
- 기간 제한(예: 출원 전후 3–5년)
- 주변 custodian 범위 축소

### Protective Order 협상
초기 단계에서 포괄적 보호명령 체결.

| 조항 | 피고 이익 |
|---|---|
| 비밀등급 체계 | Confidential / AEO / Source code tier |
| AEO 접근자 제한 | 외부대리인·전문가 중심 |
| 소스코드 프로토콜 | 오프라인 열람, 인쇄 제한, 로그 |
| Prosecution bar | AEO 열람한 원고측 출원대리인의 관련 출원 제한 |
| Clawback 조항 | FRE 502(d) 기반 비의도 생산 특권 보호 |

🌏 **한국기업 메모:** 국경간 생산 조항(한국 문서 생산이 한국법상 권리 포기를 의미하지 않음, 타 절차 전용 금지 등)을 명시하는 것이 유리.

## 8. Discovery 분쟁 대응

### 우선 meet-and-confer
대부분 관할은 분쟁 모션 전 선의의 협의 의무를 요구. 협의 기록을 서면으로 남길 것.

### 단계별 escalation
```
분쟁 발생
  ↓
meet-and-confer
  ↓ (미해결)
입장 정리 서한
  ↓
판사에게 분쟁서한 또는 motion to compel/protective order
  ↓
마지스트레이트 심리
  ↓ (불리한 결정)
14일 내 지방법원 판사 이의(기준: clearly erroneous/contrary to law)
```

실무상 대부분 분쟁은 판사 단계 전 해결됩니다. 핵심은 "합리적 입장과 선의 협의" 기록입니다.

## 10. 2026 개정 부록: 생성형 AI 데이터의 ESI 편입

### A. Legal Hold 범위에 AI 로그를 명시

소송보존 통지서에 다음 AI 관련 데이터 소스를 명시적으로 포함합니다.

- 사내/상용 LLM 프롬프트·응답 로그
- 플러그인/툴 호출 기록
- RAG 검색·인용 추적 로그
- 모델 감사/모더레이션 로그
- 피소 기능 관련 AI 코드생성 이력

Hold 발동 시 자동삭제/순환정책을 즉시 중지하고, 공급업체 보유 로그도 계약 범위 내에서 보전합니다.

### B. 2025~2026 AI 증거개시 결정의 실무 함의

법원은 본안과 직접 관련된 AI 대화 데이터는 대규모 제출을 명할 수 있고, 반대로 관련성 약함·과도한 부담이 있으면 비례성으로 제한합니다. 따라서 초기에 수집 범위(관리자, 질의 설계, 샘플링, 프라이버시 보호조치)를 문서화해야 합니다.

### C. 특허 민감 업무의 AI 사용 통제

회피설계·리버스엔지니어링·경쟁사 특허 분석에는 다음을 의무화합니다.

1. 변호사 주도 과업 정의
2. 사건번호/특권 태깅된 작업공간 사용
3. 특권·비특권 보존 구역 분리
4. 월간 준수 점검
